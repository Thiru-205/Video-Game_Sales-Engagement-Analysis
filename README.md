# Video Game Sales & Engagement Analysis

## Project Overview

In this project, I worked with video game data to understand sales, ratings, reviews, platforms, publishers, and genres. I cleaned and analyzed the data using Python and SQL, and created a Power BI dashboard to visualize the results.

## Tools Used

- Python
- Pandas
- Google Colab
- MySQL Workbench
- SQL
- Power BI

## What I Did

- Cleaned and prepared the datasets using Python and Pandas.
- Explored the data to understand sales, ratings, reviews, and player engagement.
- Combined the game and sales datasets for further analysis.
- Used SQL to check and analyze the data.
- Created different queries to find trends across years, platforms, publishers, and genres.
- Created a Power BI dashboard to present the analysis visually.

## Dashboard

The Power BI report contains:

- Project Overview
- Game Sales & Engagement Analysis
- Global sales by year
- Global sales by platform
- Global sales by publisher
- Global sales by genre
- Top games by global sales
- Rating vs global sales
- Reviews and engagement analysis

## Key Findings

- 2013 had the highest number of games in the dataset and also showed high global sales.
- X360 had the highest global sales among the platforms analyzed.
- Nintendo had the highest global sales among the publishers analyzed.
- Action was the highest-selling genre.
- Grand Theft Auto had the highest global sales among the selected top games.
- Most of the higher global sales were seen for games with ratings between around 3 and 4.

## Dataset

The project uses video game information along with sales, ratings, reviews, and engagement-related data.

The final combined dataset contains 1,649 records and 24 columns.

## Project Goal

The main goal of this project was to practice data cleaning, data analysis, SQL, and Power BI by working with a real-world style dataset and presenting the results through an interactive dashboard.
